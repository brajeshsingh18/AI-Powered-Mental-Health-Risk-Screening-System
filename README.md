# AI-Powered-Mental-Health-Risk-Screening-System

## Overview

The Mental Health Risk Analysis System is a Machine Learning-based application designed to analyze behavioral, academic, and lifestyle factors associated with mental health risks among students. The system leverages data-driven insights to identify potential risk patterns and support early awareness through predictive analytics.

This project was developed as a collaborative academic project to explore the application of Artificial Intelligence and Machine Learning in the mental health domain.

---

## Features

* Mental health risk assessment using Machine Learning
* Data preprocessing and feature engineering pipeline
* Categorical feature encoding using One-Hot Encoding
* Trained predictive model for risk analysis
* User-friendly interface for real-time predictions
* End-to-end deployment-ready workflow
